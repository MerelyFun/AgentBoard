## 已落地

- React + Vite + TypeScript 工作台：三项目阶段摘要、四角色多实例列表、项目/角色/状态/搜索筛选、执行详情、关键事件及每次事件的证据与结论。
- 默认空态；显式演示；本地 JSON 导入相互隔离。真实本地导入采用 `tools/report.py` 的 v1 事件，刷新清除，不联网发送。

- 桌面及手机布局，无横向溢出。设计、浏览器实图与比较记录在 `docs/design/`。
- Git 初始化为 main。Pages workflow 已准备：PR 检查，main 或手动发布；支持仓库子路径，部署权限隔离。尚未执行远端 workflow。
