# AgentBoard 游戏工作室

本次按用户要求改为共享办公室界面。完整参考是 `office-concept.png`；旧白灰表格方案归档于 `flat-design-archive.md`，不再作为当前样式约束。参考图中的人员、名称、数字均为视觉演示，运行时不使用图片中的数据。

## 视觉与组件

- 森林绿侧栏、冷浅 sage 主画布、白色控件，木色仅用于办公室地面/家具。标题“游戏工作室”，副标题“每一次上报，都是团队的新进展。”。
- 紧凑项目摘要 → 活跃范围与查询筛选 → 共享办公室 → 执行列表与事件。保留三项目、任务、大小阶段、最后上报、状态和数据来源。
- 办公室以一张无人背景呈现窗、绿植、书架与木地板；原生 HTML 项目标牌分三工作区。可重复透明人物工位图集由每个真实执行独立驱动，按实例稳定选择外观。
- 所有标签、任务、状态与点击范围为代码原生内容。图片不承担进度数据；不把整张概念图贴成网页。
- 工位点击打开原有详情，保留完整实例/执行编号、两级阶段与证据。真实来源不填演示人员，搜索无匹配或空项目显示无人的桌椅。

## 数据与响应式

- 八类真实 role 贯通 CLI、Edge、数据库和网页；不根据摘要猜岗位。美术可提交；只有 verifier 可正式验收；parent 是任务来源，非职级。
- 办公室只对应当前过滤后的活跃上报；超过 20 分钟转待确认。画面不能证明进程仍在执行，提交也不等于验收通过。
- 桌面三项目共享地板，人数可自然增长，不按岗位合并并行实例。窄桌面减少每区列数；手机按项目纵排，人物与文字并列，触点与任务信息保持可读。
- 保留项目/角色/状态/关键字过滤、活跃/待确认/历史/全部范围、显式演示/本地导入、登录/退出和详情 Escape 关闭。支持键盘和减少动态效果。

## 验证

发布前检查桌面与 320/390/768 等窄屏的内容、溢出、详情、筛选、空态、图片和控制台；对照参考与最新浏览器截图。云端使用明确 QA 标记，只清理本轮精确记录，不修改游戏阶段或原有任务。验证结果和发布版本记入 `../STATE.md`。
