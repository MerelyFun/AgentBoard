# AgentBoard 多执行工作室

当前布局以 `scalable-office-concept.png` 与 [多人设计说明](scalable-office.md) 为准：按项目聚焦、固定场景和可翻页工位，名单与事件有界展示。V2 三张运行图片继续原样复用，其生成和来源记录保留如下。

当前参考为 `office-concept-v2.png`。按 `game-art`、`create-game-assets`、`game-ui-ux`、`game-feel` 重做空间、资产和信息层次；具体约束见 `art-direction-v2.md`，源稿、尺寸、透明度、SHA 和验收记录见 `asset-manifest-v2.json`。

- 白色侧栏、暖白画布、青绿点缀。三个项目摘要和筛选保持紧凑，让办公室成为主视觉；不显示无权威来源的进度百分比。
- 房间、共享桌与人物沿用同一俯视相机、柔和卡通材质和左上光源。每个项目使用共享桌岛，四席成组，超过四个执行增加桌岛；项目之间保留通道。
- 人物与椅子是独立透明图集，远排位于桌后、近排位于桌前。空项目只有无人桌。每个实际活跃 run 各有可操作工位，不按岗位合并并行实例。
- 工位旁仅显示岗位与状态小胶囊。任务、完整两级阶段、时间、实例和证据保留在原生详情及下方列表；所有文字、控件与数据为 HTML。
- 手机使用办公室内项目页签查看局部场景，保持人物尺度；全局选定单项目时只显示该项目。保留原生筛选、任务列表、焦点与 Escape。动态效果轻微且不阻挡操作，尊重减少动态偏好。
