# AgentBoard 界面规格

内置 Image Gen 生成的完整应用概念。桌面原图 `dashboard-concept.png`（1586 × 992，约 16:10）；窄屏原图 `dashboard-mobile-concept.png`（756 × 2079）。屏幕中的任务、时间、运行状态全部是演示数据，项目阶段仅用于展示结构，不构成当前真实运行证据。

## 信息与容器

- 桌面：固定白色侧栏 216–220px；顶部白色工具条 64px；主内容在浅灰画布上，四周 24–36px。
- 首屏依次为标题、三项目摘要条、Agent 列表与事件侧栏。没有大指标、百分比、趋势图。
- 项目摘要为一个白色横条，内部三等分，使用细竖线分隔；不做三张分离的浮动卡片。
- 下方约 70% 宽度 Agent 列表、30% 关键事件，间距 16–24px。1440 宽时，侧栏 216px，主区宽 1224px，内边距 24px，事件栏约 300px。
- Agent 列表每行同时显示角色/实例、项目、任务、大阶段、小阶段、任务状态、最后上报时间。初始概念为六条/三类角色；最终按用户后续确认增加技术负责人，共四类角色、七条示例。
- 栏目间留白约 24px。单表格行 54–64px，高度通过内容自然撑开。组件无层层嵌套卡片。

## 颜色与字体

| Token | 值 | 用法 |
| --- | --- | --- |
| `--canvas` | `#F7F8FA` | 主画布，冷浅灰 |
| `--surface` | `#FFFFFF` | 侧栏、工具条、表格、摘要条 |
| `--text` | `#20262D` | 主文字 |
| `--muted` | `#78818D` | 元信息、提示 |
| `--border` | `#E5E8EC` | 1px 边线、表格分隔 |
| `--accent` | `#188B80` | 强调、进行中 |
| `--accent-soft` | `#E8F5F2` | 选中导航 |
| `--warning` | `#B77916` | 阻塞、演示模式 |
| `--purple` | `#7C5CFC` | 待验收、3Match 项目标记 |
| `--radius` | `6px` | 控件、外框圆角 |

无背景插画、渐变、明显投影。少量状态色必须同时配文字，不用颜色独自表达状态。

字体使用 `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif`。中文标题 28px/1.4、600；栏目标题 18px/1.4、600；正文 14px/1.5；辅助文字 12–13px/1.5；全部工具栏控件显式设置 13px。窄屏标题 24px。数字/时间用 tabular-nums。

图标为 16–18px、1.6–1.8px 细线风格，圆角端点。导航采用网格、设置齿轮、时间采用时钟、搜索放大镜、可展开行采用小 chevron。Agent 角色图形为简单几何标记，不使用照片头像。

## 可见文案

- 品牌：`AgentBoard`
- 页面：`项目总览`
- 主标题：`三个项目，一个工作台。`
- 副标题：`阶段、任务与关键行动，一目了然。`
- 演示提示：`演示模式`、`以下均为演示数据`
- 侧栏：`游戏项目`、`3Match`、`CatAndDog`、`IncrementalXxx`、`设置`
- 侧栏底部：`主动上报 · 阶段清晰`
- 设置入口：`连接设置`
- 摘要字段：`当前小阶段`、`最后上报`、`暂无阻塞`
- Agent 区：`Agent 动态`、`6 个示例`、`搜索任务…`、`全部角色`、`全部状态`
- 表头：`角色 / 当前任务`、`大阶段 / 小阶段`、`状态`、`最后上报`
- 状态：`进行中`、`待开始`、`待验收`、`阻塞`
- 事件区：`关键事件`、`演示`
- 事件区说明：`仅展示关键上报，长时间未更新不代表停止。`

## 交互与响应式

- 项目导航过滤摘要、Agent 和事件；总览恢复全部。选中态为浅青底与青色文字。
- 搜索按角色实例、任务、项目、阶段匹配；角色与状态筛选可叠加。无匹配时为清楚的空状态。
- 点击 Agent 行打开详情抽屉，展示完整阶段、角色实例、当前任务、状态与最近事件。点击遮罩或 Escape 关闭；键盘可达。
- 连接设置为对话框，显示数据来源与连接状态；演示切换必须明确，断线不能无提示换成演示。
- 1024px 以下事件区排到 Agent 下方，摘要允许纵向排列；避免挤压长阶段名。
- 720px 以下隐藏桌面侧栏，顶部改为品牌、演示、设置；项目选择采用完整宽下拉。
- 窄屏项目摘要成为一个白色分隔列表。Agent 表格按行变成多行信息列表，同一行任务下始终保留大阶段与小阶段；没有横向滚动。
- 窄屏筛选搜索占满一行，两下拉控件各占半行。关键事件在列表后自然继续滚动。
- 不在窄屏靠删除阶段字段节省空间，不假设模型报告任务完成就表示验收通过。

## 实现比较重点

1. 白色应用表面与冷浅灰画布保持一致，不改成暖灰。
2. 保留 216px 侧栏、64px 顶栏、单摘要横条与右事件轨的桌面构图。
3. 14px 内容和 12–13px chrome，中文长任务不截掉关键阶段信息。
4. 六行 Agent 的行高和信息密度，角色、任务、阶段、状态层次清楚。
5. 明确演示标识；时间只表示最后上报，不能暗示独立观测到真实进程。
6. 输入、筛选、项目选择、详情、设置必须有真实交互结果。

原始生成提示保存在 `prompts.md`。生成工具为内置 Image Gen，无需 API key；原图已复制到项目。

## 最终浏览器比较记录 · 2026-10-22

实图：[桌面](browser-desktop.png)、[手机](browser-mobile.png)。由 Browser/IAB 的 screenshot API 保存，在同一轮使用 `view_image` 检查桌面/手机概念及实图，没有使用外部浏览器替代。桌面测得 CSS 1586×993（概念 1586×992，相差 1px 来自缩放取整），手机 390×843；当前浏览器常规尺寸亦已检查。内嵌浏览器有 110% 缩放，截图显式传入物理 clip 范围，解决默认截图右侧裁切；DOM 实测 scrollWidth 不大于 innerWidth。

| 比较项 | 概念依据与实现结果 | 修复或有意差异 |
| --- | --- | --- |
| 构图/容器 | 白侧栏、顶栏、单一三等分摘要条，下方左列表右事件轨 | 保留容器；事件轨修为 31%，摘要最小高度修为 248px |
| 文字层级 | 标题 28px、正文 14px、辅助 12–13px | 提升任务、阶段、状态和事件字号；工具栏有显式字号。系统字体支持离线运行，字形会随系统变化 |
| 色彩/装饰 | 冷浅灰画布、白表面、青强调、紫/青/金项目标识、细边线 | 已对应；没有背景插画、渐变或额外装饰 |
| 图标 | 四格总览、齿轮设置、时钟、几何角色标识 | 修正实心四格与齿轮尺寸，技术负责人新增紫色菱形 |
| 首屏文案 | 品牌、主副标题、导航、筛选、阶段字段和演示标识 | 静态文案一致；状态与阶段示例按最终协议校正，下列差异为功能需要 |
| 密度 | 三项目摘要、表格式任务列表与事件时间线 | 四角色七条示例替代三角色六条；不为塞入首屏而缩小文字，可正常纵向滚动 |
| 小屏 | 隐藏侧栏、项目下拉、摘要纵排、搜索独占一行、两筛选并排、任务保留两层阶段 | 390px 检查通过，无横向溢出；点击项目筛为 3 条，恢复可见全部 |

首屏文案差异核对：任务、阶段和时间是显式演示数据，可变；`6 个示例` 调为 `7 个示例` 体现四角色；`待验收` 调为 `已提交` 避免开发模块提交被误读为集成验收；`待开始` 调为 `待确认`，没有未启动的虚构执行；阻塞摘要显示“有阻塞”，详情提供具体原因。增加真实空态、本地导入来源及未连接提示，是避免示例被当作事实所需。连接设置增加本地导入与 Supabase 待接入说明，点击事件展示该次证据，点击执行展示完整阶段与历史。

核心交互、真实 CLI 文件导入和错误保留均已验证；修复了模态框在 StrictMode 下意外关闭和历史事件证据不可查看的问题。最终实现已按设计逐项对照验证，除上述明确的功能调整和系统字形差异外，无待修的实质视觉偏差。
